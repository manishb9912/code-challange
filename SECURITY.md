# Security

This file covers the security controls in the product catalogue PoC: what threat each one addresses, what is implemented now, and what production would add. Controls marked **(tested)** have automated tests. Others were checked by hand against the running docker stack (see [docs/ai-notes.md](docs/ai-notes.md)).

## Threats, mitigations and production additions

| Threat                                      | Mitigation in this PoC                                                                                                                                                                                                                                                                                                                                                                                                                                        | Production addition                                                                                                                                                                                  |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **XSS (UI)**                                | React escapes output. `dangerouslySetInnerHTML` is banned by ESLint (`@eslint-react/dom-no-dangerously-set-innerhtml`, also `dom-no-script-url`). Upstream descriptions render as text **(tested: a malicious description renders literally)**. Links use internal routes only.                                                                                                                                                                               | Same, plus CSP violation reporting (`report-to`) to a collector.                                                                                                                                     |
| **XSS (content injection via images)**      | The API only passes through `https:` image URLs from `IMAGE_HOST_ALLOWLIST`; anything else (http, `javascript:`, `data:`, look-alike hosts) becomes a same-origin placeholder **(tested)**.                                                                                                                                                                                                                                                                   | Serve images from our own S3/CloudFront origin instead of hotlinking.                                                                                                                                |
| **XSS (CSP)**                               | Strict CSP from nginx (web) and helmet (API): `default-src 'self'; img-src 'self' https://fakestoreapi.com data:; script-src 'self'; style-src 'self'; object-src 'none'; base-uri 'self'; frame-ancestors 'none'; form-action 'self'`. No inline scripts or styles in the build. zod's JIT is disabled (`jitless`) because its `new Function` probe would trip the CSP. Checked in headless Edge: 0 violations on every route. API header test **(tested)**. | CSP reporting; add the image CDN host.                                                                                                                                                               |
| **XSS in the sales email**                  | Every interpolated value in the HTML part goes through `escapeHtml`; a plain-text part is always sent **(tested with `<script>` in name and message)**.                                                                                                                                                                                                                                                                                                       | Same; consider a template engine with auto-escaping if the templates grow.                                                                                                                           |
| **SQL / NoSQL injection**                   | **There is no database in this PoC, so there is no SQL injection surface.**                                                                                                                                                                                                                                                                                                                                                                                   | Rule recorded in CLAUDE.md: parameterised queries / ORM only, never string-built SQL. The future DB adapter sits behind `ProductSource`, so routes never see SQL.                                    |
| **Path injection / SSRF into the upstream** | `:id` and `:slug` must match `^[A-Za-z0-9_-]{1,64}$` before reaching any service **(tested: traversal, illegal characters, over-length)**. The adapter builds URLs under a fixed base from config with `encodeURIComponent`, refuses any URL outside that base, short-circuits ids that cannot exist, and uses `redirect: 'error'` so a response cannot bounce us to another host **(tested)**.                                                               | Egress allowlist (VPC endpoint / proxy) so the API can only reach known hosts.                                                                                                                       |
| **Email header injection**                  | CR/LF and other control characters are rejected in `name` and `email` by the shared schema **(tested)**. The subject is built server-side and stripped of control characters **(tested)**. Addresses are passed as nodemailer address objects, not concatenated strings.                                                                                                                                                                                      | Same.                                                                                                                                                                                                |
| **ReDoS**                                   | No RegExp is ever built from user input; search uses `includes` **(tested with `.*+?` etc.)**. All validation regexes are anchored and simple.                                                                                                                                                                                                                                                                                                                | Same.                                                                                                                                                                                                |
| **Code injection**                          | ESLint errors on `eval`, implied eval, `new Function` and imports of `child_process`/`vm`.                                                                                                                                                                                                                                                                                                                                                                    | Same.                                                                                                                                                                                                |
| **Prototype pollution**                     | Strict zod schemas reject unknown keys, including `__proto__` and `constructor` **(tested)**. Fastify `onProtoPoisoning`/`onConstructorPoisoning: 'error'` reject poisoned JSON with 400 **(tested)**.                                                                                                                                                                                                                                                        | Same.                                                                                                                                                                                                |
| **CSRF**                                    | The API is stateless with **no cookies and no sessions**, so the browser has no ambient credentials to abuse. Defence in depth on state-changing routes: `Origin` must be in `ALLOWED_ORIGINS` (403, also when missing) and `Content-Type` must be `application/json` (415), which blocks cross-site HTML form posts **(tested)**. No CORS plugin: same-origin via proxy ([ADR 0006](docs/adr/0006-same-origin-no-cors.md)).                                  | If cookies/auth are added: `SameSite=Lax/Strict; Secure; HttpOnly` cookies plus CSRF tokens (`@fastify/csrf-protection`).                                                                            |
| **MITM / transport**                        | Upstream must be `https://` in production (config fails fast otherwise) **(tested)**; TLS verification is never disabled. SMTP must use TLS in production (`SMTP_SECURE` or `SMTP_REQUIRE_TLS`, enforced by config) **(tested)**. HSTS is sent by the API only when `NODE_ENV=production` **(tested)**. Images are https only. **Locally, everything is plain HTTP on 127.0.0.1.**                                                                            | TLS at CloudFront/ALB with ACM certificates, HTTP→HTTPS redirect, HSTS at the edge.                                                                                                                  |
| **Spoofed client IP**                       | `trustProxy` comes from config (`TRUST_PROXY_HOPS`). nginx overwrites `X-Forwarded-For`, and the API trusts exactly one hop in compose.                                                                                                                                                                                                                                                                                                                       | Set hops to match CloudFront + ALB.                                                                                                                                                                  |
| **Rate limiting / abuse / cost**            | `@fastify/rate-limit` per client IP: global 100/min on all routes (health probes exempt); **5/min on `POST /enquiries`** (protects the inbox, email budget and sender reputation). 429 with `Retry-After` and `RateLimit-*` headers **(tested)**. Honeypot field: filled → 201 with nothing sent and a PII-free `honeypot_triggered` log **(tested)**. No customer confirmation email, so the form cannot be used to send mail to third parties.              | Shared Redis store for limits (in-memory limits are per instance); AWS WAF rate-based rules at CloudFront/ALB, including the **hourly/daily enquiry cap**; CAPTCHA (e.g. Turnstile) if spam appears. |
| **Upstream throttling**                     | Cache + single-flight means user traffic never fans out to Fake Store; `p-limit` caps concurrent upstream calls (5); 5 s timeout **(tested)**.                                                                                                                                                                                                                                                                                                                | Circuit breaker if the upstream becomes a paid/limited API.                                                                                                                                          |
| **DoS / resource limits**                   | Body limit 10 KB (413) **(tested)**, nginx `client_max_body_size 16k`; URL length cap 2048 (414) **(tested)**; param length ≤ 64 via schema; search term ≤ 100; pagination `limit` ≤ 100 **(tested)**; connection/request/keep-alive timeouts; bounded cache (1,000 entries).                                                                                                                                                                                 | WAF, autoscaling, CloudFront caching.                                                                                                                                                                |
| **Clickjacking**                            | `frame-ancestors 'none'` and `X-Frame-Options: DENY` from nginx and the API **(API tested)**.                                                                                                                                                                                                                                                                                                                                                                 | Same.                                                                                                                                                                                                |
| **Security headers**                        | nosniff, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`; no `X-Powered-By`; nginx `server_tokens off` **(API tested)**.                                                                                                                                                                                                                                                                   | CloudFront response headers policy.                                                                                                                                                                  |
| **Information leakage**                     | One central error handler maps typed errors to `{ error: { code, message, details?, requestId } }`. Unknown errors become a generic 500; framework and upstream messages are never echoed; no stack traces **(tested)**. Validation details include field paths and our own messages only, never received values.                                                                                                                                             | Same, plus error tracking (e.g. CloudWatch / Sentry) keyed by `requestId`.                                                                                                                           |
| **PII in logs**                             | Structured pino logs. Code logs only ids (`enquiryId`, `productId`); redaction censors `name`, `email`, `phone`, `message`, `authorization`, `cookie`, `set-cookie` and `SMTP_PASS` as a safety net **(tested: redaction and a full enquiry flow at trace level)**. Proxy-supplied request ids are accepted only if they are short and safe, so they can't inject into logs **(tested)**.                                                                     | Log retention policy; CloudWatch Logs with KMS.                                                                                                                                                      |
| **Secrets**                                 | All config from env, validated at startup; error messages name variables but never echo values **(tested)**. `.env` is gitignored, `.env.example` holds dummy values only, `.dockerignore` excludes `.env`. gitleaks in CI (run locally too: no leaks in history or the working tree).                                                                                                                                                                        | AWS Secrets Manager / SSM Parameter Store injected into the ECS task.                                                                                                                                |
| **Supply chain**                            | Exact pinned versions plus a committed lockfile; `npm ci` in CI and Docker; `--ignore-scripts` in Docker builds; `npm audit --audit-level=high` in CI; Dependabot for npm, GitHub Actions and Docker images. Few runtime dependencies (each justified in its commit).                                                                                                                                                                                         | Pin GitHub Actions by SHA; SBOM and image scanning (ECR scan / Trivy).                                                                                                                               |
| **Containers**                              | Multi-stage builds; the API runtime image has compiled JS + production dependencies only and runs as `node` (uid 1000); web runs on `nginx-unprivileged` (uid 101); read-only root filesystems; all Linux capabilities dropped; `no-new-privileges`; HEALTHCHECKs; ports bound to 127.0.0.1; no secrets in images (verified).                                                                                                                                 | Fargate task roles with least privilege; ECR image scanning.                                                                                                                                         |
| **Privacy**                                 | Enquiry PII is used only to send the email and is never stored. A privacy notice sits under the form.                                                                                                                                                                                                                                                                                                                                                         | Exact consent/legal wording is an **open question** for the entrepreneur; data-retention policy for the sales inbox.                                                                                 |

## Known gaps

- **No CAPTCHA.** It would need a third-party account. The rate limit, honeypot and Origin check are the mitigation.
- **In-memory rate limits and cache.** They're per instance and reset on restart. Production needs a shared store (Redis/ElastiCache), and the seams exist (`@fastify/rate-limit` store option, `Cache` port).
- **No hourly enquiry cap in-process.** The brief asked for 5/min **and** 20/hour. `@fastify/rate-limit` applies only one limiter per request, so a second window is silently skipped (found by tests). The agreed decision: enforce 5/min in the API and put the longer window at the edge (AWS WAF).
- **Local stack is plain HTTP** and runs the API with `NODE_ENV=development`, because Mailpit has no TLS. Production config refuses non-TLS SMTP and non-https upstreams.
- **Enquiries aren't persisted.** If the mail provider is down, the user sees an error and must retry; nothing is queued.
- **Dev-only audit findings**: `npm audit` reports moderate advisories, all from one `minimatch` advisory in lint/test tooling. Production dependencies report 0 vulnerabilities (`npm audit --omit=dev`).
- **Images are hotlinked** from fakestoreapi.com (the only browser request to a third party, allowlisted in the CSP).
- **Swagger UI** (`/api/v1/docs`, dev aid, off by default) uses its own hash-based CSP; its bundle applies one inline style that the CSP blocks and reports. It is cosmetic (all operations render) and the CSP was not loosened for it.
- The web container's CSP must be kept in sync by hand with the API's helmet CSP (both files say so).

## Reporting

This is a proof of concept. To report a vulnerability, contact the repository owner privately rather than opening a public issue.
